# 阅读与本地书库

## 离线使用与阅读器模式

在 **我的 → 设置 → 使用方式** 调整：

- **离线适配**：默认开启。无网络时隐藏发现，书架只显示至少缓存一章正文的联网收藏；只有目录的书不会算作已缓存。本地页保持原样。
- **阅读器模式**：只保留书库与我的；未合并时显示本地，合并后显示离线可读的书架。关闭后按当前网络状态恢复导航；原书架、阅读位置和各页的滚动位置会保留。
- **合并书架**：默认关闭。开启后，书架在主动收藏的联网书之外加入本地原书与合订本，试读和缓存不会自动加入书架。封面角标区分「在线／缓存／本地」，右上角 ＋ 可导入文件或网盘书籍。底部隐藏「本地」，书架顶部可直接选择分类，同步仍从 **书架 → ＋ → 本地分类与同步** 进入。断网且开启离线适配时，只保留离线可读的合并书架、我的。取消收藏不会删除缓存或本地原书，关闭合并即恢复本地入口及原来的展示范围。
- **点书直接阅读**：默认关闭。开启后可分别勾选「发现页」「书架页」「本地页」，支持多选；未勾选的页面仍先打开书籍详情。初次开启默认全选，关闭再开启会保留已选页面。已读书从上次位置继续，未读书从第一章开始；阅读器右上角的「进入详情页」可打开简介、标签、分卷目录及书籍管理。

网络恢复后会恢复导航入口，不强行切换当前页面。短暂的 Wi-Fi／移动网络交接不会反复切换界面。这些设置均可随时关闭，不改变玻璃、动效或其他性能选项。

## 保持文库登录

登录表单中的「保持登录」用于会话过期后自动重新连接。已经登录时，可在 **我的 → 文库账号 → 保持登录** 开启，确认一次当前账号的密码；无需先退出账号。登录凭据只加密保存在这台设备，不随阅读记录备份或云书架同步。

关闭开关会清除自动连接凭据，当前有效的登录仍可使用；退出账号会一并清除。暂时断网或无法读取本机加密存储时保留记录供重试；密码更改或账号被服务端拒绝后需要重新登录。推荐、发帖、签到和收藏不会因恢复连接而重复提交。

回到 App 时直接沿用有效登录，不额外等待一次检查。重启后暂时断网、未能恢复账号时，联网后会继续恢复，无需重新打开账号页。平时使用账号和同步书架时复用已有连接，收到明确的过期结果才重新连接；切到后台后停止定时同步，无需后台常驻。

## 导入自己的书籍

在底部 **本地 → 右上角 ＋ → 导入书籍**，选择文件应用并勾选书籍，可一次导入多本。支持 TXT、EPUB、Kindle（MOBI / AZW / AZW3 / PRC）、FB2、PDF、DOC / DOCX、RTF、HTML、Markdown 与 ZIP；网盘文件选择「从网盘导入」，连接方法见[网盘导入指南](CLOUD_IMPORT.md)。导入的原书与合订本默认只显示在「本地」；开启「合并书架」后在书架展示，导入入口也改用 **书架 → ＋**。清理联网正文缓存不会删除本地原书。

本地文件默认**关联原文件**，不先把整份文件复制进应用：TXT 只保存目录位置索引；EPUB 保存目录、压缩的正文排版缓存与封面，插图按需读取原 EPUB；其他文档及压缩包保留转换、解包后实际阅读需要的文件。转换结果仍会占用空间，但不会再永久保存一份相同的原始 PDF、Markdown、Kindle 文件或 ZIP。

请保留原文件。移动文件或授权失效时，在阅读器提示或 **书籍配置 → 重新定位原文件** 选择同一份文件，章节、进度与书签不变；内容已修改的文件应作为新书导入。

从 Android 文件管理器的「打开方式」选择本 App，可直接阅读当前已授权的文件，不先要求在另一个选择器重选。可保留的授权会自动保留；App 已有共享文件访问权限时优先关联可直接读取的原路径。仅有临时授权的第三方文件仍可当次打开，系统实际撤销授权后才需要重新定位，不隐式复制整本书。

本地书详情和书籍配置不显示简介；EPUB 原书正文中的简介页仍按原书保留。

希望独立保存，可在 ＋ 菜单选择 **复制到应用**；已经关联的书也可在 **书籍配置 → 保存副本到应用** 转为独立阅读副本。TXT / EPUB 保存完整原书，经过转换的格式保留当前阅读用的 EPUB / TXT。默认方式在 **导入与目录 → 本地书籍保存方式** 修改，立即生效。已有副本不会自动转换或删除；网盘导入仍保存应用内副本。续读传书及原书同步按需读取关联文件，不把本机授权发到另一台设备。文件提供方不支持直接定位读取时会提示选择「复制到应用」，不会悄悄改用复制。

TXT 会识别常见的简繁体卷名、章名，没有目录的长文本按阅读片段拆分。默认自动识别 UTF-8、带 BOM 的 UTF-16、GB18030 和 Big5；也可在 **本地 → 显示与筛选 → 更多本地设置 → 导入与目录 → TXT 编码** 预先指定编码，香港扩展字可选 Big5-HKSCS。编码点选后立即保存，用于之后的导入，不改写已导入书籍或原始文件。

### 调整 TXT 目录与缺省章名

在同一「导入与目录」页，TXT 目录默认仍为「自动识别」。需要匹配特殊章名时，选择「自定义规则」，分别填写章节和分卷的正则表达式；分卷表达式可留空。匹配按去掉首尾空白后的单行进行，最多识别 90 字符的标题行，整行保留为章名；同时匹配时优先作为卷名。

可从「常见中文」「Chapter」「【标题】」开始修改，粘贴一小段原文后点「预览目录」，确认卷、章和顺序，再点右上角「保存」。表达式无效或处理过慢时会明确提示，原设置和已导入书籍保留；没有匹配到标题的正文仍会保留。

「原书未提供标题时」可选择「补齐章名」或「标为正文片段」。后一项只改变缺省显示名称，不影响 EPUB 已有的目录或正文标题。目录和章名设置用于后续文件、扫描及网盘导入；重复导入同一原书仍沿用已有目录、进度和书签，不自动重新拆章。

EPUB 按书内阅读顺序展示正文，保留封面与本地插图，支持普通 EPUB 2 / 3 的 UTF-8、UTF-16 目录与正文，不处理 DRM 加密。单本 TXT 上限 128 MiB，EPUB 上限 512 MiB；TXT 分块解码和建立目录，关联模式按章节位置读取原文件，副本模式保存压缩后的拆章正文。

目录优先使用原书的 EPUB 3 NAV，其次使用 NCX；封面、制作信息、简介、彩页等沿用原书名称。原书将多张彩页列为一个入口时，目录也只显示一个「彩页」，翻页仍能读完这些图页及附文。未列入目录的正文不会被删除，页码列表不会混入章节目录。点按正文中的书内文字链接可跳转到对应章节或段落；旧书在打开时恢复原书导航和可恢复的链接，不重编已有章节、进度或书签。

EPUB 图片优先使用书内声明的尺寸，未声明时按原图尺寸显示，超出阅读区域才等比缩小。小注释图标可与正文共用一页，不会被拉满整张书页。已有导入书籍会在阅读图片时自动补回尺寸信息，无需重新导入。

EPUB 保留原书声明的段前／段后距、内边距，以及空段或连续换行形成的场景留白；相邻外边距合并，紧凑对白不会一律变成相同段距。滚动与翻页使用同一份间距信息，不插入空白文字段落。已有新版排版 EPUB 在打开时补回这些信息，原段落、章 ID 和书签不变；尚未升级排版的旧书可使用下方的「升级排版」。

新导入或手动升级的 EPUB 也保留常见段落对齐、粗体、斜体、下划线、分页边界、分隔线、图片位置及混合横竖排；表格按行显示并区分各列内容。日文注音在横排时位于汉字上方，竖排时位于汉字旁，复制与朗读仍使用正文；点按原书注释标记打开说明，关闭后回到原处。装饰文字、背景图、负边距、复杂 CSS 计算及固定版式仍需进一步适配。

双语 EPUB 保留段落的语言标记与原书透明度，浅色译文不会一律变成正文颜色。在 **阅读设置 → 排版 → 本书语言** 选择「全部语言」「仅中文」「仅日文」等显示模式，点选某种语言即显示该语言，不会反向隐藏。选择只作用于当前书，并随阅读偏好备份。隐藏不删除正文，重新显示后仍使用原段落坐标；未标记语言的段落和插图继续显示。旧版排版缓存会在原书可读取时补回这些信息，无需删除书籍重新导入。

### 升级旧 EPUB、批量修复封面与整理存储

打开 **本地或合并书架 → 批量整理**，多选书籍，点右上角的魔杖「修复与整理」。三个选项可分别开启，点「开始整理」逐本处理；合订本按原卷处理，同一卷不会重复整理。停止会完成当前操作再停，失败条目说明原因，可重新选择重试。

- **升级排版**：从应用内保存的 EPUB 恢复新版排版，保留原始文件、原目录和章节标识，旧进度、书签与摘录分类对应到新版文字。先核对旧正文；不一致、缺失原书或资源损坏时不强行升级，也不清理这本书的旧正文。
- **重建封面**：从原书恢复封面；你选择过的封面仍优先显示，合订本的自选封面也不被覆盖。
- **整理存储**：EPUB 先确认插图可从原书完整恢复，再清理重复的解压副本；升级正文及定位数据完整时才清理旧正文副本。TXT 副本无损压缩转码文件与拆章正文，原书保留；关联模式没有全文副本需要整理。自选封面、未知文件、目录与阅读记录均保留。

排版与封面修复用于 EPUB，存储整理支持 EPUB 与 TXT；都不自动在后台重写旧书，也不修改下载目录的原文件。

Kindle 与常见文档在本机转换后使用同一阅读器。FB2、DOC / DOCX 保留正文与支持的嵌入图片；DOC 使用 Word 97–2003 格式，不读取加密文件，旧版 Word 文件需先另存为 DOC / DOCX。HTML / Markdown 可通过 ZIP 一起带入相对路径引用的图片。PDF 按原页分章，文字页重排正文，扫描页保留为图片；不处理加密、禁止内容提取或包含 JPEG2000 图片的 PDF。RTF 导入正文文字。ZIP 支持子目录内的上述格式，一本失败不影响其他书籍；导入完成后统一确认同系列分卷。

文件上限：EPUB / PDF / DOCX / ZIP 为 512 MiB，Kindle 为 256 MiB，TXT / FB2 / RTF / DOC 为 128 MiB，HTML / Markdown 为 32 MiB。ZIP 展开后合计最多 1 GiB、200 本。转换文档中的单张图片最多 8 MiB；损坏、加密、资源超限或存储不足会在结果卡片中提示。

## 缓存小说以便离线阅读

在小说详情页右上角打开「离线缓存」，选择「缓存全部章节」或「缓存后续 20 章」。试读自动保存的章节和主动缓存均不会自动收藏或加入书架，可从阅读历史或缓存管理再次打开；想留在书架时，请主动点「加入书架」。缓存仅用于 App 内阅读，不提供小说 EPUB／TXT 文件下载或导出。本地导入、原书同步、书签图片分享和插图保存不受影响。

缓存会一并保存所选章节里的正文图片和独立插图页，完成后显示已缓存章数与插图数量；重启 App、清理普通图片浏览缓存后仍可离线查看。之前只缓存了文字的书，无需先删除，重新选择「缓存全部章节」即可补存插图。

缓存期间可取消，失败后点「继续缓存」，只补缺失的正文和插图；图片未存完时会明确提示，不显示整本完成。清除本书缓存会一并清理这些插图，不取消收藏，也不会删除阅读进度或本地导入的原书。缓存管理位于 **我的 → 设置 → 数据与存储 → 缓存管理**。

### 扫描全部共享存储或指定文件夹

打开 **本地或合并书架 → ＋ → 扫描本地文件夹**，先选择要找的格式，再选择扫描范围。格式可多选，Kindle 选项包含 MOBI / AZW / AZW3 / PRC；下次扫描沿用上次的格式选择。

- **全部扫描**：在系统页面允许共享存储访问后，寻找设备及可访问存储卷内的书籍，不扫描其他 App 的私有目录。
- **指定文件夹**：选择支持 Android 目录授权的文件应用，再选择书籍文件夹，只授予该文件夹的读取权限；系统不允许选择下载根目录时，可选择其中的子文件夹。

扫描后先展示候选文件卡片，默认不勾选。可按格式筛选，或搜索文件名、文件夹；多个关键词用空格分隔。「全选结果」只选中当前筛选范围，切换筛选保留已选文件。确认数量后点「导入」；取消不会导入或改动原文件。

「自动扫描新增书籍」只检查已选范围，不自动导入。打开扫描页后仍需勾选确认；未选择的文件会保留为下次扫描候选，已导入且未变动的文件不重复读取。导入结束后统一确认分卷合并。点「停止自动扫描」不删除已导入的书籍。

## 切换书架视图

书架和本地列表上方用同一行显示分类、数量与「显示与筛选」。点右侧按钮，选择「立体书架 + 列表」或「仅列表」，也可调整阅读状态与排列顺序；合并书架还可筛选书籍来源。立体区展示当前筛选、排序后的前 10 本，下方始终保留全部书籍的完整列表及阅读进度、整理入口。本地达到 10 本时显示立体区；两处的视图选择分别保存。

载入立体区时，书形占位沿书架轻轻起伏，书脊与封面逐本在原位置显现；封面图片各自加载好后淡入，不等待整排完成。刷新保留现有书架和滚动位置，减少动态效果时使用静态占位。

## 用同一套分类整理书架与本地

在书架或本地列表上方点「全部书籍」，可新建、重命名和删除分类。书架的书籍操作菜单提供「移至分类」，本地书可在整理菜单或书籍配置中更改分类。两处使用相同的分类名称与归类记录，当前选中的分类分别保留；删除分类只让书回到「未分类」，不会删除书籍。

同一分类菜单中的「按作者分类」会列出当前书架或本地书库的作者及书数，选中后只显示该作者的书。作者分类根据书籍信息自动更新，不会覆盖手动分类；选择「全部书籍」恢复完整列表。

合并前，书架分类用于联网收藏，本地分类用于本地书；合并后，同一分类可以同时包含联网收藏和本地导入，已缓存的收藏仍保留离线阅读能力。来源筛选、阅读状态、离线适配与阅读器模式仍会进一步限定可见书目。

## 批量移出或删除本地书

在 **本地 → 分类与筛选栏右侧的勾选图标** 打开「批量整理」；开启合并书架后，入口在书架的同一位置。可搜索书名、作者，逐本勾选，或全选当前搜索结果；更换搜索词保留已选书籍。本地单本书的整理菜单也提供「批量选择」。

点底部「移除」后，选择「仅移出书架」保留文件并支持恢复，或选择「同时删除本机文件」并确认。合订本包含的分卷一起删除；只处理 App 管理的副本，不删除下载目录和网盘原文件，阅读进度与书签保留。个别书籍操作失败时，其他已选书继续处理，失败条目保留选择供重试。

点底部「移动分类」，可把多本书统一移入已有分类，也可先新建分类。取消或保存失败时保留选择，原文件与阅读记录不变；本地和合并书架使用相同入口与分类。

## 调整 App 的莫奈配色

在 **我的 → 设置 → 阅读与外观 → 主题配色** 选择「原色」「系统取色」或「自选配色」。系统取色使用 Android 12 及以上提供的壁纸色盘；不支持的设备仍可自选颜色。主色生成配套的浅／深色，页面、玻璃、按钮、开关、提示与骨架沿用同一套颜色，现有动效不变；阅读器的纸张和控件配色仍独立。

选择「图片取色」后，可点建议色，也可在图片上点选或拖动，确认「使用此颜色」后应用。图片只在本机处理，临时副本会清理，只保存选定颜色；不改动原图，也不把这张图设为阅读背景。自选颜色还可调整色相、饱和度、明度或输入六位 RGB 色值。配色选择随阅读偏好备份保留。

「图标莫奈取色」独立于界面配色，沿用原有主题图标能力，关闭时提供不含单色层的原图标。Android 13 及以上、且桌面支持并启用主题图标时，图标颜色由系统桌面决定，不保证与 App 自选色相同；桌面可能缓存图标或强制着色。

## App 和阅读器使用不同字体

打开 **我的 → 设置 → 阅读与外观 → 字体**，分别选择 App 字体和阅读器字体。阅读器默认「跟随 App」，也可单独选择系统字体、思源宋体或导入字体；每项附一行实际字形预览，阅读设置的「阅读字体」可直接进入同一配置。

思源宋体不随安装包预装，点选后下载约 21.6 MiB，完成后可离线使用。在「可下载字体」中可取消下载、删除已下载字体或重新下载。未下载时使用系统字体；旧的字体选择仍保留，重新下载后恢复。删除正在使用的字体会恢复默认，导入的其他字体和原文件不受影响。

点「导入字体」选择 TTF 或 OTF 文件，单款最多 32 MiB。导入后字体复制到应用内部，原文件移动后仍可使用；移除正在使用的字体时恢复默认。更换阅读字体保留当前段落与书签位置。阅读记录备份保存字体选择，不包含字库；在另一台设备使用自定义字体时，需在该设备导入并选择。

## 展开一卷，再选章节

书籍详情页的目录按卷展示。点卷名展开或收起，下面的章序仍是整本书连续的章序。继续阅读会直接进入上次的章节。

阅读器的目录默认展开当前卷；搜索章名、卷名或章序可以找到收起卷里的章节。点定位按钮回到当前章节。

手动向下滚动到章末会续接下一章，章首继续向上滑动可回到上一章末尾；横排、竖排翻页在边界继续左右翻动即可跨章。跨章沿用所选翻页效果和速度，不额外播放章节入场动画；向前进入下一章首页，向后返回上一章末页。预先准备相邻正文，尚未准备好时保留当前正文；加载失败也保留当前位置，可再次翻动重试。调整排版、恢复位置或拖动进度条到章末不会自行换章；目录末尾不循环。

系统侧边返回第一次显示「再滑动一次退出阅读」，两秒内再次返回即可退出；不会弹出确认框。继续阅读操作后取消这次退出意图。顶部返回按钮仍直接退出，抽屉打开时先关闭抽屉。

### 整书定位与查找

底部目录的「章节进度」可切换「本章／整书」。整书比例按章节计算，拖动只预览目标卷、章和章内比例，点「前往这里」再切换，不会反复加载经过的章节。

在「章内查找」点「整书查找」，可搜索本地原书及已缓存正文；点结果进入对应章节并高亮。默认不联网补齐正文，存在未缓存章节时可明确选择联网查找；关闭查找会停止继续读取。最多显示前 500 个匹配位置，可缩小关键词范围继续查找。

## 按自己的习惯阅读

### 只为这本书调整排版

打开 **阅读设置 → 排版 → 排版范围**，选择「本书」，再调整字体、字号、行距、配色、阅读方式、四边距、段落间距、缩进与对齐。其他书仍沿用通用设置；本地与联网书都可分别保存。

切回「通用」会立即使用通用排版，但保留这本书先前的设置，再选「本书」即可恢复。切换时从当前阅读行接续；「恢复默认排版」作用于当前范围，不删除书签或阅读进度。亮度、系统状态栏、按键与手势、翻页效果和速度仍共用，不需要逐本设置。

在「文字细节」中选择常规、适中或加粗字重，调整字间距。横排改变文字间距，竖排改变同列字距；拖动时只保留当前滑块，直接预览正文。阅读记录备份在勾选恢复阅读偏好时恢复单书设置；自定义字体仍需另行导入。

### 阅读控件与操作

阅读器右上角统一使用「阅读设置」入口，包含排版、操作、书签和听书：

- **排版**：阅读方式、翻页效果和配色直接点选项按钮；阅读字体打开带预览的字体选项页。字号、行距、页边距、段落间距、首行缩进与两端对齐在同一面板调整。
- **首行缩进**：与两端对齐同时开启时，首行仍保留两字宽缩进；换页后的续段不重复缩进。字号变化、查找高亮与文字选择沿用同一排版位置。
- **页边距**：同一条滑块可切换「左右／左／右／上／下」。选择「左右」一起调整水平边距，其余选项分别调整对应边，不影响其他边。拖动字号、行距、边距或段落间距时，面板只保留当前滑块，可直接观察正文变化。
- **本章进度**：在底部目录的「章节进度」选择「本章」。拖动时隐去面板其他部分并透过背景预览当前位置，跨过轻刻度时有触觉反馈；松手后保存位置。章首、章末和章内查找也集中在这里。
- **阅读配色**：按钮、底部 Dock、阅读设置和听书面板跟随纸张适配底色与文字对比，已打开的面板也会同步变化；只改配色不会重新分页。
- **阅读背景**：在「排版 → 阅读背景」导入图片，再选「填满／完整」并调整浓度；拖动时透过面板预览正文。背景沿用「通用／本书」范围，阅读配色继续决定纸张底色和控件颜色。点「纯色」停用，垃圾桶删除当前背景并清除使用它的单书设置；原始图片不变。最多保留 12 张，每张原图 20 MiB 以内，导入为静态图片后离线使用。换设备时需在新设备重新导入图片。
  支持 JPEG、PNG、WebP、GIF、BMP 与 WBMP，动图只取第一帧。导入时生成最长边不超过 2048 像素的 PNG 副本，保存在应用内部，不依赖相册路径；原图移走或删除后仍可使用。删除背景只删应用副本；清除应用数据或卸载应用会移除这些副本。
- **阅读模式**：向下滚动、横向翻页、竖排翻页。横排和竖排均左右翻页，横排正文按段落、竖排正文按列接力移出与进入，保留文字清晰度。静止时保留设置的页边距；翻动时正文可经过两侧留白移至屏幕边缘，与章节标题、时间和电量行一致，不在页边距处截断。点按、音量键或自动翻页共用这套过渡，手势翻页直接跟随手指，松手后不重播入场。
- **控件显隐时正文重排**：在「操作」中设置，默认开启。显示控件时正文为顶部和底部控件留出空间，隐藏后恢复阅读区域；保留同一原文坐标，相同布局始终使用相同分页，反复切换不会累积断页或减少内容。关闭时控件覆盖正文，不改变正文几何。字号、字体、页边距和窗口尺寸变化仍正常重排。
- **章节入场动画**：在「操作」中设置，默认关闭。开启后，打开书籍或从目录进入章节时播放额外的入场动画；章末／章首的跨章操作仍沿用所选翻页效果，不用入场动画替代翻页。
- **翻页效果**：在排版中选择「段落接续」「无动画」「平移」「覆盖」或「纸页翻动」，默认仍为段落接续。纸页随手指弯曲，显露纸背与柔和阴影，反向拖动可收回；手机单页与大屏对页均适配。横排、竖排使用同一选择，不改变排版位置；轻扫即可翻页，小幅调整后松手会回到原页。低性能模式关闭动效时静态切换，插图与正文仍完整显示。
  章节标题、页码和应用内时间电量行随页面一起翻动，平移、覆盖和纸页动画的纸面延伸至上下安全区。系统原生通知图标和手势条仍由系统绘制；要使用随页翻动的时间电量行，可开启「隐藏系统状态栏」。
- **翻页速度**：在翻页效果下方选择「舒缓／标准／利落」，默认沿用标准速度。点按、音量键与自动翻页使用所选速度；手指拖动时仍直接跟手，松手后的收尾速度同步调整。切换速度不重排正文，「无动画」时不显示这一项。
- **大屏对页**：平板或折叠屏展开、两侧空间足够时，翻页模式自动并排显示两页，一次翻过一组。横排先左后右，竖排先右后左；窗口变窄后恢复单页，保留阅读位置。竖排重排从当前页开头的文字继续，不回退到前面几段；展开／恢复沿用档案滑入过渡，书页避让系统报告的折叠中缝。
  选择「纸页翻动」时，以中间书缝为转轴翻动纸面；其他效果仍沿用各自的过渡。
- **横排／竖排切换**：保留当前文字所在的阅读位置，用逐段／逐列滑入衔接两种排版，不重新显示骨架屏。
- **操作**：开启「分区点按翻页」后，可选择常规、左手或右手布局；常规布局中，横排左侧上一页、右侧下一页，竖排方向相反，中间显示控件。下方的「左右点按均为下一页」默认关闭；开启后，左右两侧都前进，中间仍显示控件，滑动翻页不变，关闭后恢复之前选择的点按布局。滚动模式下前进一屏。音量键只在阅读器前台翻页，打开抽屉或离开阅读器后恢复原用途。
- **隐藏系统状态栏**：在「操作」开启，时间与电量显示在原系统状态栏的位置，分别靠左、靠右；章节标题与页码在下方另占同一行。自动避让系统报告的摄像头切口；仍觉得靠边时，拖动下方「时间与电量留边」直接预览位置。正文保留设置的页边距。滚动模式去掉底部模糊和固定留白，顶部模糊范围也更紧凑。阅读设置、目录和章内查找保留这一状态及阅读亮度，离开阅读器后恢复系统状态栏和系统亮度。
  华为的系统悬浮导航球是独立设置；在华为设备的「操作」页可查看关闭指引并主动打开系统设置，不会随着隐藏状态栏而被 App 强制关闭。
- **自动滚动**：设置速度后开始，点按正文、手动拖动或切到后台即暂停；滚动至末章结束时停止。
- **亮度**：只改变当前阅读窗口，不修改手机的系统亮度。离开阅读器恢复系统亮度。
- **书签**：保存当前位置，再点按书签回到对应段落并短暂高亮。

首次进入阅读器时默认隐藏控件，并提示「点击屏幕显示控件」。之后记住上次的显示状态，再次进入时直接恢复，直接阅读的加载阶段也不先显示顶部控件。点按正文可切换控件，边缘模糊随控件平滑退出；正文是否为控件重新留出空间，由「控件显隐时正文重排」决定。滚动模式为当前显示的系统状态栏或应用内状态行保留安全区。

长按正文优先选择完整句子，再拖动系统选区手柄扩大或缩小范围。浮动工具条提供「复制」「书签」「插图」；阅读器和 **我的 → 书签** 使用同一份记录。保存后的摘录可在书签页导出为带图标水印的图片。

书签条目上的分类按钮可新建或选择分类；「我的 → 书签」顶部可按分类筛选。阅读器和书签页同步修改同一条书签，分类随阅读记录备份保留，旧备份不会覆盖更新的分类或已清空的分类。

点「插图」可查看当前卷的插图缩略图，包含独立插图章节和正文内的图片；没有分卷信息时整理全书插图。已读取的章节不重复请求，独立插图章节优先显示，其余章节后台整理。点缩略图进入可翻看、缩放和保存的大图，返回后保留原阅读位置。这是浏览入口，不修改正文中的插图位置。

正文自带插图地址时按原位置显示。已导入同版本 EPUB 时，根据插图前后的唯一正文匹配自动补回位置；只有独立插图章节、缺少位置线索时保留原插图章节，不根据编号猜测位置。阅读设置不再提供手动排版入口。

点按详情页封面或正文插图，可打开大图。图片使用全屏画布，初始以适应大小的 90% 居中展示，顶部控件与模糊浮在图片上。双指可放大到屏幕边缘、继续平移或缩小；双击切换放大与初始大小，**单击关闭大图**。缩放后先平移图片，不误切换到下一张。右上角保存按钮保留图片原始格式与像素，Android 10 及以上保存到相册 `Pictures/Wenku8`，较早版本可选择保存位置。

图书列表不提供封面长按弹出预览；查看封面从详情页进入。作者和标签书单可以继续打开其他作品；再次打开当前浏览路径里的作品会复用原页面，最多保留最近四层作品浏览。

### 为本地书更换封面

打开本地书详情右上角的配置，点「更换封面」选择图片，立即保存到本机；「恢复原书封面」可撤销更换。合订本还可直接选择其他分卷的封面，不改动该卷原来的封面；未单独设置时跟随首卷。修改书名、作者、分类或阅读正文都不会覆盖自选封面，原书和原始图片不改写。

## 查看本版变化

**我的 → 关于 → 本版更新** 先显示几条摘要，点「查看详细更新说明」可按重要说明、账号与兼容、阅读体验、书签续读与听书、本地导入、书架与性能逐页查看；也可左右滑动，或点「上一页／下一页」。入口迁移会写清位置和使用方式。新版本首次进入时优先显示详细说明，最后一页点「完成」后，同一版本不再自动展示。「我的」首页不再重复放更新卡片。

新版本提醒、「关于」中的在线更新说明和本版说明统一支持 Markdown：标题、粗体、斜体、列表、任务列表、引用、表格、分隔线、代码和链接。较宽的表格与代码可左右滑动；链接和配图在点按后通过浏览器打开，不自动加载远程配图或触发下载、安装。香港与台湾繁体界面会转换说明文字，链接地址和代码保持原样。

「关于」页的「重要说明」常驻免费开源、内容来源、版权与使用提醒、服务和数据风险。在线内容来自轻小说文库，本地书籍由用户自行导入；本项目为第三方客户端，应用开源许可不授予小说、封面和插图的使用权。完整说明也放在本版详细说明的第一页。

## 使用香港或台湾繁体

在 **我的 → 设置 → 阅读与外观 → 语言** 的下拉菜单选择简体、香港繁体、台湾繁体或跟随系统，交互与外观模式一致。阅读设置内也提供同一语言菜单。界面、系统编辑菜单及阅读正文采用对应中文区域；正文在显示时转换，保留原书、图片链接、书签与朗读位置。超过 32 KiB 的章节用字转换放在后台，切换语言不改写缓存和同步原书。

## 按标签发现作品

在发现页打开 **分类与排序 → 标签**，可多选标签，也可搜索或输入标签名称；「清空」和「应用」放在标签区域顶部。应用后留在发现页，用原来的立体书架与列表浏览**同时包含所选标签**的作品。清空标签恢复全部，选择榜单则切回对应榜单。书籍详情页的单个标签仍可打开该标签书单；两种入口向下滚动都能继续加载，不限制为 20 本。

## 评论与回复

在书籍详情页点「评论」，可查看评论列表、打开完整正文和回复；点「写评论」发表新主题，或在主题内点「回复」。发表使用已登录的轻小说文库账号。尚未发表的内容自动保存为本机草稿，提交成功后清除；失败时保留正文供重试。

## 选择刷新率偏好

打开 **我的 → 设置 → 性能与动效 → 帧率偏好**。默认「自动高刷」请求当前分辨率下的最高可用刷新率；「系统调度」交回系统决定，也可点选设备实际支持的档位。高刷新率适合滚动和翻页，低档位适合更重视耗电的使用场景。

「屏幕模式」显示当前屏幕刷新率，不是 App 的实测帧率。设置使用 [Android 帧率 API](https://developer.android.com/media/optimize/performance/frame-rate)，不改变屏幕分辨率；系统省电、温控与厂商策略仍可能限制实际采用的档位。

## 与轻小说文库账号共用收藏

在 **我的 → 账号** 登录后，账号卡显示平台头像和同步状态。首次合并 App 与平台已有的联网收藏，此后同步两端的新增和移除；离线时等待网络恢复。阅读位置、本地导入文件和正文缓存不随收藏移除而删除。本地书籍跨设备同步使用下方的同步文件功能。

## 两台设备共用一个同步文件

1. 打开 **本地 → 显示与筛选 → 更多本地设置 → 跨设备同步设置**，选择「新建同步文件」。
2. 在 Android 文件选择器侧栏选择已登录的 OneDrive 或 Google Drive，保存文库生成的 `.wenku8sync` 文件。
3. 回到文库，点按「立即同步」。
4. 在另一台设备选择「已有同步文件」，打开云盘中的同一个文件，再点按「立即同步」。

开启合并书架时，先从 **书架 → ＋ → 本地分类与同步** 进入，再打开书库设置。

云文档入口必须支持持久读写授权；是否显示入口取决于云盘应用及系统文件选择器。没有入口时，先检查相应云盘应用的登录状态和文档接入能力。

同步先读云端，再合并本地书籍、联网收藏、阅读位置和书签，最后写回。较新的阅读位置优先；删除本机原书不会删除云端副本。退出书库不会中断已开始的同步，再次进入时需等上一次云文档操作完成后再操作。当前为手动合并同步，不在后台定时上传，尽量避免两台设备同时写入同一个文件。

自定义 TXT 目录规则和缺省章名选择随对应原书同步，接收端不使用自己的新书导入设置重新拆章。使用这类同步文件时，两台设备都需更新到支持该功能的版本；两端已有同一原书但目录规则不同时，会停止合并并保留本机阅读记录。只同步记录时，需先同步使用自定义目录的原书。

同步前检测到云端变化会停止写入，让你重试；写入前的云端副本和完整待写副本保留在本机。发生写入错误时，可从同步面板的恢复入口先恢复到本机，再新建同步文件。一次最多同步 200 本、256 MB 压缩文件。

## 同一 Wi-Fi 自动续读

打开 **我的 → 设置 → 局域网续读**，在两台设备启用。它会自动发现同一 Wi-Fi 的设备；点选自己的另一台设备，核对两端显示的六位数字一致后，分别点「确认连接」，不需要输入地址或连接码。首次连接需两台都停在续读页，已配对的设备以后在 App 前台自动重连，地址变化后也会重新发现。

### 把当前这本书接到另一台设备

在本地书的阅读器中打开 **目录 → 章节进度 → 在其他设备上续读**，选择已经配对的设备。两台 App 都保持前台：

- **对方没有这本书**：传送这一本书，保留原书、既有目录、插图、封面和合订本结构。手机上的原书保留，不会搬走。
- **对方已有同一本书**：只发送当前位置，不再复制原书。
- **接收完成**：另一台出现「继续阅读」，点按后从接到的位置打开；未点按前不切走正在阅读的书。若已在阅读同一本书，原位跳到接收位置；若是另一本，替换当前阅读页，返回仍回到书库，不反复叠加阅读器。打开的阅读工具会先收起，设备卡片与提醒跟随当前阅读配色。

进度显示在设备旁的圆环内，可点中央停止；失败后可重试，不留下半本书。若同一原书在两端使用了不同目录规则，保留对方原有数据并提示，不覆盖已有目录或阅读记录。

平时自动交换两端已有书籍的较新阅读位置，并增量同步书签、摘录分类、书籍分类名称及归类记录；新增、修改和删除都会同步，不复制账号、密码或整座书库。在线书需先在另一台加入同一本书；定向传书仅用于自己的本地导入书籍。

首次连接会补齐已有书签与分类，以后只传变化记录。两台 App 均需保持前台；断开后可各自修改，重连再合并。相同记录在两端分别修改时，会在 **局域网续读 → 同步冲突** 保留所有版本，选择一项后继续同步。删除与修改冲突时暂按删除处理，可以在冲突页明确恢复另一版，避免旧设备把已删除内容又带回来。显示方式、排序和当前分类筛选仍由每台设备单独保存。

本地书采用不同目录或旧／新排版时，先保留双方记录并提示，完成同样的排版升级后再合并定位，不把书签硬塞进不对应的段落。升级不影响已保存的摘录文字与分类。

App 进入后台后停止监听。若网络隔离设备或阻止自动发现，可展开「手动连接」，只把连接码交给自己的设备；解除配对使旧连接失效，阅读记录仍保留。手机热点的发现能力还需按设备验证。此功能不使用云服务器，与上面的手动同步文件互相独立。

## 连续听书与续听

在阅读器打开 **阅读设置 → 听书**，点按「从阅读位置听起」；已有记录时也可以选择「续听 · 第几章」。听书位置与阅读位置分别保存。

- 双击正在朗读的段落暂停，再双击继续；双击其他文字段落从那里开始。
- 语速支持 0.5～3 倍，每格调整 0.05 倍；切换段落和暂停后继续仍沿用所选速度。
- 当前段落使用明显的整段底色与侧边标记，暂停时继续保留。竖排使用连续的列底色，不逐字绘制小方块。
- 「本章进度」可拖动定位；语速、跟随朗读和睡眠定时在面板下方调整。手动滚动会暂停自动跟随；点正文底部的「开启跟随」，即可平滑回到朗读位置，隐藏阅读控件时也能使用。它不会重新开始音频或改变暂停状态。
- 个别文字无法合成时会拆成短句重试，连续失败会暂停并提示；可重试、跳过当前语段或更换音色。联网失败时保留当前位置。
- 锁屏通知和耳机按键可控制播放。停止听书后仍保留续听位置。

### 双语书按语言朗读

在 **听书 → 本书朗读语言** 选择「自动匹配」，按段落切换当前音源中对应语言的音色；也可选择「仅朗读中文」「仅朗读日文」等选项。选择按书保存，与排版中的「本书语言」独立：只听中文时，日文仍可显示。

在 **音源与音色 → 分语言音色** 分别选择中文、日文等语言的声音；每次只列出该语言的可用音色。音色按当前音源或系统引擎保存，其他书也沿用；选回「自动匹配」可清除指定音色。更换音色保留当前原文位置和暂停状态。

优先使用 EPUB 的段落语言标记；未标记时识别明确的日文假名和韩文，其余文字沿用常用音色的语言，不把仅含汉字的段落强行判成另一种语言。系统引擎只在所选引擎内匹配，自定义接口只使用配置声明的语言，不自动切换服务。

没有对应语言的可用语音模型就跳过该语言，并在面板提示；本章所选语言都没有模型时停止朗读，不用其他语言代读。指定音色不可用时也跳过，不自动换成其他声音；可重新选择音色或恢复自动匹配。模型缺失可安装对应语音数据后重新检测，或自行更换音源再试。预加载、短句重试和续听沿用实际音色与原文坐标，不改变正文及书签。

### 选择手机已安装的朗读引擎

在听书面板的音源中选择 **系统引擎**，列表会检测手机已安装的 TTS 引擎，提供「系统默认」及具体引擎。直接点名称使用该引擎的默认音色；点名称右侧的音色按钮查看可用音色。选择会保存，不自动试听；原有自然在线和自定义接口继续可用。

引擎是否离线取决于安装的引擎与音色，列表会按引擎提供的信息标明。没有检测到引擎、缺少语言数据或服务不可用时，可从「系统语音设置」处理后重新检测，也可切回其他音源；不需要另外安装一份引擎到文库内部。

## 使用自己的语音服务

在 **我的 → 设置 → 阅读与外观 → 自定义语音接口**，或 **听书 → 配置自定义语音接口** 填写：

| 项目 | 填写方法 |
| --- | --- |
| 合成地址 | 服务的完整 HTTPS POST 地址，如 Azure 的 `https://<区域>.tts.speech.microsoft.com/cognitiveservices/v1` |
| 音色 ID | 服务支持的音色名称，例如 `zh-CN-XiaoxiaoNeural` |
| 语言 | 与音色一致，例如 `zh-CN` |
| 认证 | 无认证、Azure 订阅密钥或 Bearer 访问令牌 |

接口按 [Microsoft Text to Speech REST](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech) 接收 SSML，使用 `audio-24khz-48kbitrate-mono-mp3` 输出。普通网页地址和只返回 JSON 的接口不能直接作为音频合成地址。

「保存并使用」会保存配置并切换音色；「试听接口」会发送一条测试句并播放。点按「停止试听」或离开配置页会取消正在合成的试听，也会停止播放，之后可以重新试听。服务可能按提供方规则计费。密钥通过 Android Keystore 加密保存在本机，不进入阅读记录备份和云同步。需要恢复公共在线音源时，在听书面板选择「自然在线」，或移除自定义接口。

阅读器的排版与操作参考 [Moon+ Reader 的阅读功能](https://www.moondownload.com/chinese.html)，云文档接入使用 [Android Storage Access Framework](https://developer.android.com/training/data-storage/shared/documents-files)。
