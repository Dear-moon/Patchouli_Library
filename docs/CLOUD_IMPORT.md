# 从网盘导入书籍

打开底部的 **本地 → 右上角 ＋ → 从网盘导入**。支持 TXT、EPUB、Kindle、FB2、PDF、DOCX、RTF、HTML、Markdown 和 ZIP；可以点击一本直接导入，也可以勾选多本批量导入。导入完成后，原书保存在本机，可离线阅读。开启 **设置 → 使用方式 → 合并书架** 后，底部隐藏「本地」，原书与合订本统一显示在书架，导入使用 **书架 → ＋**，分类与同步从同一菜单的 **本地分类与同步** 进入。本地原书不写入云端收藏。

手机内的文件使用 **本地 → 右上角 ＋ → 导入书籍**。选择文件应用后，勾选要导入的书籍；支持多选的文件应用可一次选择多本。文件逐本处理，重复文件不会新增副本；单本失败时其余书籍继续导入，结果页会列出失败文件。

EPUB / PDF / DOCX 上限 512 MiB，Kindle 上限 256 MiB，TXT / FB2 / RTF 上限 128 MiB，HTML / Markdown 上限 32 MiB。解析在后台逐本进行；转换文档中的单张图片上限 8 MiB。格式处理见[阅读与本地书库](READER.md#导入自己的书籍)。

ZIP 最大 512 MiB，解包总量不超过 1 GiB，最多 200 本。会查找子文件夹内支持的电子书与文档，统一导入并确认同系列分卷；不递归展开内层 ZIP。部分书籍失败时保留成功结果，并以独立卡片列出文件与原因。压缩包与网盘原文件不会改动。

## OpenList / WebDAV

1. 在 OpenList 或 NAS 上开启 WebDAV，给阅读账号授予读取权限。
2. 添加连接，填写完整地址、用户名和密码。OpenList 地址通常是 `https://你的域名/dav/`，也可以限定到其中一个目录。
3. 选择“连接并浏览”，进入书籍目录后导入。

百度网盘、OneDrive、Google Drive 等可先挂载到自己的 OpenList，再从这里导入。使用需要代理下载的网盘时，在 OpenList 对应存储中开启下载代理。仅列出目录和可导入的书籍、ZIP，不修改网盘文件。

HTTPS 默认开启；可信局域网中的 HTTP 服务需手动打开“允许 HTTP 连接”。HTTP 会明文传输连接凭据。

## 夸克 Cookie（实验性）

1. 在电脑浏览器登录自己的 `pan.quark.cn`。
2. 打开开发者工具的“网络”，选择网盘文件列表请求，复制请求头中 Cookie 的值。
3. 在“夸克网盘 → 配置夸克 Cookie”中粘贴，选择“连接并浏览”。

Cookie 需要包含 `__puus`。服务端更新会话时会同步更新本机记录；登录失效后重新填写。此入口使用网页版接口，接口或风控变化可能影响使用。下载速度仍由网盘决定。

## S3 / S3 兼容对象存储

1. 选择 **S3 → 添加 S3 连接**，填写服务的 Endpoint、存储桶名称、区域、Access Key ID 和 Secret Access Key。Endpoint 不包含桶名；区域使用服务商提供的值，未指定时为 `us-east-1`。
2. 可填写目录前缀（例如 `books/`）限定浏览范围。临时凭据还需填写 Session Token。
3. 默认使用路径式寻址，适合多数兼容服务；需要 `桶名.Endpoint` 的服务可关闭该选项。选择 **连接并浏览** 后，按文件夹选择书籍导入。

此**导入入口**只使用列目录和读取对象权限（`s3:ListBucket`、`s3:GetObject`），不会上传、移动或删除桶内对象。支持目录分页和中文文件名；HTTPS 校验保持开启。HTTP 仅供用户明确允许的可信局域网服务使用。要在设备间同步原书和阅读记录，请使用下方的 **S3 云端同步**。

## 管理本地书库

- 点击分类名称，可以新建、重命名、删除分类；删除分类不会删除书籍。
- 书籍右侧“…”可以移动分类或删除本机原书。
- 打开本地书籍详情，点击底部 **配置书籍**，可修改书名、作者、简介与分类，或删除本机原书。修改信息不会改变原书、阅读位置或书签。
- 发现、书架、本地的搜索均在右上角展开；书架按当前是否合并检索对应的书籍，本地只检索导入书籍。
- 显示设置提供立体书架、列表和宫格。宫格只选择 **自动、小、中、大**，列数随窗口和字号调整；旧的行列数配置会归入相近的封面大小。立体区展示本数可设置，下方保留全部书籍。
- 移除本地书籍前会确认删除应用内副本；下载目录、网盘原文件、阅读进度和书签保留。不再提供隐藏后的恢复库，旧版本仅移出但未删除的书会重新显示。
- 可按最近导入、最近阅读或书名排序；TXT 编码设置对之后的导入生效。

## 把多卷合并成一本书

批量导入全部完成后，应用会统一列出识别到的同系列分卷，按卷号排序。确认要合并的系列后，点击 **确认合并**；也可以选择 **暂不合并**，保留各卷独立显示。之后仍可打开书籍右侧 **… → 合并分卷**，或在详情页的书籍配置中进入。

1. 在结果页点击 **调整书名与分卷顺序**，可选择新建合订本或加入已有合订本。
2. 确认书名与要合并的分卷。分卷名称可直接修改，拖动右侧横线调整阅读顺序。
3. 点击 **合并为一本书**。本地书库显示一部作品，详情目录按卷展开，阅读器可连续阅读各卷。

原 EPUB 保留，文中插图、阅读进度和书签按原章节对应。之后可在 **管理分卷** 中添加新卷、调整顺序，或恢复为独立书籍。删除合订本的本机原书会删除它包含的全部分卷，确认框会显示卷数。

## 跨设备同步

在 **本地 → 书库设置 → 跨设备同步设置** 中选择存储位置。可分别开关原书（含修改后的书籍信息）、阅读进度与书签、本地分类；点击 **立即同步** 后，先读取云端、合并较新的记录，再写回同步文件。没有后台自动上传，也不会随每次翻页传输原书。

### S3 云端同步

1. 选择 **S3 → 配置 S3 同步**，填写 Endpoint、存储桶、区域和凭据。已有 S3 导入连接可以预填；保存同步连接之前，不会启用上传。
2. 两台设备使用同一个存储桶、目录前缀与同步文件路径。默认路径为前缀内的 `wenku8/library.wenku8sync`，它是独立同步文件，不会覆盖桶内原书。
3. 给此文件授予 `s3:GetObject`、`s3:PutObject` 权限；首次同步还需能判定路径不存在（AWS S3 可用对应前缀的 `s3:ListBucket` 权限）。S3 兼容服务需要支持 `If-Match` 和 `If-None-Match` 条件写入。
4. 保存后选择同步内容，点击 **立即同步**。其他设备按同样配置同步，即可合并书库和阅读记录。

同步按整个 `.wenku8sync` 文件传输：最多 200 本、原始内容合计 512 MB，最终同步文件不超过 256 MiB。网络与存储流量由所用服务计费。只同步阅读记录时可关闭 **本地原书**；云端已有原书会保留。

如果另一台设备在本次读取后更新了文件，本次写入会停止，不覆盖对方。再次点击同步将重新读取并合并。上传中断或结果未确认时也不直接重发写入；本机保留写入前的云端副本与本次完整同步副本，可在错误提示下合并恢复到本机。断开 S3 同步不会移除 S3 导入连接，也不会删除云端同步文件。

### 系统文件位置

选择 OneDrive、Google Drive 或其他位置，通过系统文档选择器新建或打开同一个 `.wenku8sync` 文件。需要对应网盘应用提供可读写的系统文档入口；仍通过 **立即同步** 手动合并。

分卷合并信息随原书同步，每卷只保存一份原文件；分卷顺序与章节标识在另一台设备上保持一致。

WebDAV、夸克和 **网盘导入中的 S3** 仍只用于导入书籍。S3 同步连接独立保存，修改导入连接不会改变同步目的地。连接密码、Cookie、S3 密钥和令牌使用各端已有的本机安全存储（Android Keystore、iOS Keychain、HarmonyOS 安全存储），不进入阅读备份或书库同步文件。
