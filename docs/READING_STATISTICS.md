# 用底部 Dock 看不同的阅读记录

打开「我的 → 统计」，用底部 Dock 切换分类。Dock 上方的日期按钮显示当前区间，点开后选择近 7／30／90／365 天或自定义日期；旁边的「视图」按钮调整要看的统计模块。阅读的四类统计共用同一个已保存区间，切换分类会保留各自的滚动位置；再次点当前分类可以回到顶部。图片报告入口保留在页头。

- **总览**：所选区间的阅读时长和活跃情况，以及当前文库的库存摘要。
- **节律**：日曲线、日历、月份与星期、24 小时圆环、连续阅读会话和夜读。星期 × 时刻只保留在阅读日记，不再重复展示。
- **书目**：每天读过的书、已测单书时长、月份足迹、初见与完成，以及当前藏书和进度。
- **记号**：当前书签、划线和引用；本期有日期的记号单独统计。阅读纪念也在这里。
- **触摸**：本机累计的触碰网格和记录开关，底部工具行显示“本机累计”，不提供无效的日期筛选。切回阅读统计后保留原来的区间。

没有内容的数据分类会从 Dock 省略，当前分类变空时回到总览。触摸设置始终保留；全空时总览只显示一处阅读引导，不绘制空图或未知字段。已经观测到的 0 仍是有效值，例如已记录自然日里的零分钟。

## 区间记录与当前快照分开

时长、时段、会话、首次翻开、完成和有创建日期的记号按所选日期计入。藏书、当前章节进度和保存的引用是页面加载时的当前快照，会标出快照日期，不回填成历史库存。

旧版只有日总量的记录仍可查看已知日期、月份和星期的时长；不会把总量分配成小时、会话或单书时长。缺少日期的旧记号保留在当前文库，不分摊到选中区间。没有样本的子图与字段直接省略。

书籍元数据缺失时，真实时长、日期与汇总仍保留，但不显示占位书名或虚构题材。保存的引用和章节原文不受影响；有真实书名时才显示书名署名。

触摸的默认开启、隐私和批量保存规则见 [触摸指纹](TOUCH_FINGERPRINT.md)。

## 选择图片里真正需要的内容

图片报告的「报告内容」按当前数据提供七组：阅读节律、阅读足迹、阅读日历、相伴书单、阅读进度、藏书构成、摘录与书签。没有记录的组不显示；取消选择会同时移除编辑预览、完整预览和保存图片中的对应内容。

阅读足迹是活跃日、连续阅读段等摘要；阅读日历是真实逐日格子，两者可独立选择。近 7／30／90 天和短自定义区间使用月历，超过 93 天的区间使用紧凑周列热图，避免全年月历挤占其他章节。格子区分未记录、已记录零值及实际阅读时长。八套主题保留各自的插画、章节和版式。

保存成功使用自动消失的 Toast；失败原因保留在操作附近以便重试。旧版的日历开关迁移为足迹和日历两个选择，之后保留用户主动调整。
