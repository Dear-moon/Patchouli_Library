# 平台与规则边界

App 提供通用网络、规则解析、账号存储、阅读、缓存及本地导入能力。平台协议、域名、页面选择器、请求参数和平台展示信息由外部规则提供。

平台由 `engine.platform` 声明分组、名称和编号前缀；会话由 `engine.session` 声明共享范围；EPUB、配套字体、HTML 简介和筛选均通过 `engine` 声明选择通用实现。没有声明的平台使用书源本身的名称与 JS 前缀。

站点规则不存放在本仓库，不打包进安装包，也不进入公开 CI 测试样本。独立规则仓库可以生成可手动导入的 JSON，规则协议变化通常无需重新编译 App。新增引擎能力或修改声明协议时需要更新 App。

历史书籍与章节标识仍保存在现有索引中。规则可为数字章节标识声明提取表达式，避免迁移时重排原有章节 ID。
