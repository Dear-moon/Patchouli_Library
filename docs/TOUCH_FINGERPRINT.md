# 看看阅读时，指尖最常落在哪里

像平时一样阅读，正文触碰会默认在本机累计。打开 **我的 → 统计 → 底部「触摸」**，可以暂停、继续或清空记录；有样本后显示竖屏、横屏各自的热图、左右半屏占比和常驻区域。

- 尚无本地记录时默认开启；已有的暂停设置会保留。关闭后保留已有次数，重新开启继续累积。
- 点击、滑动和长按都只记录最初接触正文的位置，不记录滑动轨迹。
- 只统计已加载、可见的正文阅读区。阅读控件、设置面板和输入框不计入；正文已进入文字选择状态、被其他页面遮挡、键盘可见或应用在后台时也不计入。
- 竖屏使用 12×20 网格，横屏使用 20×12 网格。坐标按正文视口归一化，不混合横竖屏，不受像素密度或字体大小影响。
- 颜色表示当前方向的相对频次。左右占比描述屏幕位置，不推断使用哪只手。
- 尚无样本时仅显示记录设置，不绘制零计数、空热图或空分布，也不显示无效的清空操作。任一方向有样本时可以清空两种方向；损坏记录的清空恢复入口也会保留。某个方向没有样本时不绘制该方向的图，不把另一方向的数据混入。
- 触摸是本机累计，选中「触摸」时以“本机累计”替代日期筛选。切回其它统计分类会保留原来的日期区间。
- “清空触摸记录”会在确认后同时清空两种方向，阅读时长、进度和书签不变。

## 记录和性能

每次符合条件的触碰只递增一个整数，不触发页面通知、绘图、JSON 编码或磁盘写入。热图仅在查看本页时绘制，没有持续动画。两个方向合计固定 480 个 `Uint32` 计数，数组占 1,920 字节，不随触碰次数增长。

有变化时每 30 秒批量保存；离开阅读器、应用切后台、暂停和清空时提交。系统突然结束进程时，尚未提交的一批次数可能丢失。保存失败保留内存计数，并在触摸页提供重试。

记录使用独立的 `reading_touch_fingerprint_v1` 本地偏好键，只包含开启状态、开始日期和两个网格计数。没有书名、正文、逐次坐标或事件时间；不加入文库备份和同步。

开始日期来自首次实际计入的正文触碰，打开统计页或开启开关不会提前计时。清空后重新等待首次触碰；暂停后再开启沿用已有计数和开始日期。无法读取或格式不支持的记录保持原样并暂停采集，确认清空后才能重新开始。

## 共享实现

- `reading_touch_store.dart`：固定网格、设置、批量写入和恢复。
- `reader_touch_surface.dart`：正文区域的被动 `Listener`，不加入手势竞争。
- `reading_touch_page.dart`：入口、开关、静态热图、左右分布和清空。
- `pages.dart`：在现有 `ReaderTapSurface` 外接入采集，复用正文活动资格与选择状态。

Android、iOS 和 HarmonyOS 使用同一份 Dart 实现，不增加原生权限或通道。
