# 每个有效交互都有触感

打开书籍、点按卡片、切换选项、显隐阅读控件，都有一次短促反馈。拖动有刻度，长按有确认，边界有止点，完成和失败有不同的结果反馈。保留立体书架和阅读进度的正常振动密度，让触感跟得上操作，而不是通过少震来改善手感。

在 **设置 → 性能与动效 → 振动反馈** 中，可以关闭全部反馈，也可以分别调整按钮与选择、书架滑动、阅读翻页、拖动刻度、长按、边界和结果提示。每类独立选择轻／标准／强；改档后用该类触感试振一次。统一强度会修改所有类别的档位，不与分类强度叠加。关闭开关保留原来的分类设置，重新开启即可恢复。

| 场景 | 触感 |
| --- | --- |
| 按钮、书籍、卡片、链接、关闭弹层 | 点击被识别或手势确认关闭时，一次短促动作反馈 |
| Dock、选项、开关、输入框 | 用户选中或进入输入时，一次轻刻度；程序恢复焦点不触发 |
| 立体书架切换书本 | 沿用 0.4.6 的短刻度与靠近中心时机，至少间隔 65 ms；快甩不补发 |
| 字号、亮度、进度、取色等拖动 | 首次有效微调有反馈，之后按刻度变化触发；阅读进度保留原有密度和 70 ms 间隔 |
| 普通上下滚动 | 触屏和开始滑动不振动；到达边界给止点，惯性与程序滚动不振动 |
| 手动点按／滑动翻页 | 短而轻的落页反馈，跨章一致 |
| 打开、播放、暂停等按钮 | 短促单次动作反馈，仅成功识别点击后触发 |
| 复制、收藏、手动导入完成 | 原生完成反馈，在结果确认后触发 |
| 确认移除、导入部分失败 | 短促提醒，不模拟长按或长震 |
| 当前操作失败 | 原生失败反馈，同类连续反馈限频 |
| 长按、拖动排序 | 长按识别及有效换位时反馈；文字选择沿用系统反馈，不叠震 |
| 插图双击、双指缩放、拖移 | 双击或首次有效变换时反馈；原地触摸不触发，取消不追加反馈或提交翻图 |
| 下拉刷新 | 拉至可刷新位置给刻度；刷新完成或失败给对应结果反馈 |

自动入场的图标、页面加载、预读、后台同步和设置恢复不附带振动。禁用控件、被滚动取消的点击、隐藏页面也不触发。键盘输入、系统文件选择器和官网 WebView 内的交互由系统控件负责，不给整块界面加触摸监听。书架在下一本书接近中心（距中心 0.12 格）时触发；比较跨过的位置，不依赖某帧刚好落进窗口。相邻中心之间的抖动不反复敲击，吸附结束不重复补震。

所有反馈至少分隔 65 ms，避免嵌套控件与即时结果叠成两下；同类完成／失败另有限频，但不阻挡之后无关的选项或书架操作。复制、收藏等有明确结果的按钮在按下时保持安静，只在结果确认后反馈。未播放的刻度直接丢弃，不排队。

## 在业务结果处选择语义

```dart
showNovelFeedback(context, '链接已复制', haptic: HapticCue.success);
```

标准按钮、`LiquidGlass`、`ContentPanel`、`JellyTapSurface` 默认使用 `action`，带选中状态的 `GlassTextButton` 使用 `selection`；只有配置有效回调才会触发。自定义动作使用 `AppHaptics.play(context, cue)`。如果刻度或业务结果负责触感，外层按钮传 `haptic: null`，避免重复。书架使用独立的 `shelfStep`，不与密集进度条共用极轻预设。

玻璃开关只在实际切换时给一次短刻度。共享滑块提供内部刻度和端点反馈。阅读滑块有专用刻度时传 `haptics: false`，由阅读滑块统一处理指针、键盘及无障碍调整。松手不补震，快速跨过的刻度不排队。App 适配层关闭组件自带反馈，统一经过同一个节流器，只消除同一次操作中拖动、松手和外层点击的重复叠震，不以减少正常反馈来改善手感。组件独立使用时仍默认启用原有反馈。振动设置页的开关和分段控件用 `haptics: false`，保存成功后由 `AppHaptics.preview` 按新值反馈一次；关闭时不补震。

Android 标准档的普通点击、翻页和刻度继续使用 `CLOCK_TICK`；长按用 `LONG_PRESS`，边界用 `CONTEXT_CLICK`，完成/失败用系统确认/拒绝预设。轻／强档在 Android 12 及以上使用设备支持的短促 TICK／CLICK primitive，通过缩放强度调整，不拉长时间；成功与失败保持短促的不同节奏。硬件不支持时使用系统语义预设。`VIBRATE` 权限只用于这个可调效果，Android 13 及以上标记为 `USAGE_TOUCH` 由系统控制触感开关，旧版本检查触感设置，均不使用忽略系统设置的标志。原生拒绝播放后不追加备用振动。[Android 触觉兼容性](https://developer.android.com/develop/ui/views/haptics/haptics-apis)

iOS 标准档沿用选择、短触、长按和结果反馈；轻／强档使用 impact intensity。结果提示保持系统成功／警告／失败语义，因其没有强度接口，该分类只显示开关和试振。实际强度随设备和系统设置调整。

维护入口：`lib/app_haptics.dart`、`lib/app_ui.dart`、`lib/glass_controls.dart`、`AppHapticsPlugin.kt` 和 `ios/Runner/AppDelegate.swift`。回归覆盖有效动作、微调、连续刻度、弹层关闭、滚动边界、无障碍、取消和后台静默；物理手感由真机体验确认。
