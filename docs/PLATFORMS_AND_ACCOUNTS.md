# 书源与账号

公开版本不内置站点规则。首次启动后，进入「书源管理」，通过文件、链接或粘贴导入规则 JSON；导入前可预览并选择书源。同一个 `bookSourceUrl` 会更新规则，保留启用状态和现有书籍关联。

发现页左上角按规则声明显示平台名称、标识与译文变体。「我的」跟随当前平台展示账号，统一账号页可管理其他已导入平台。多个变体仅在规则声明共享会话时共用账号。

登录方式由规则声明：原生表单、手动网页登录，或两者同时提供。普通浏览、搜索和后台验证不会自动弹出网页登录。请确认登录页标注的实际提交站点，不要向未信任的书源提交账号。

账号信息通过现有本机加密会话存储保存。表单已保存不表示服务器已确认登录，界面分别显示验证中、已登录、登录失效和请求异常。导出规则不包含本机账密、Cookie 或登录令牌。

书架可按平台选择本机收藏或云端收藏。读取云端收藏不会自动写入本机书架，也不会修改站点收藏。签到、云收藏和资料展示是否可用，取决于书源声明及站点实际权限。

更新规则时保留 `bookSourceUrl`、书籍地址和章节地址，有助于保留书架关联、缓存、书签与进度。不要在规则中嵌入个人凭据。

参见[引擎声明协议](SOURCE_ENGINE.md)与[自定义书源](CUSTOM_SOURCES.md)。
