# 添加自己的阅读卡片

在 App 的小组件设置中新建卡片，选择内容、样式和外观，再从系统桌面添加对应尺寸。每张卡独立保存，可以同时展示今日阅读、阅读纪念和摘录。

- 内容：今日阅读、本周热力、阅读日历、阅读纪念、摘录卡。
- 样式：四季手帐、读者档案、夜读之城、胶片三幕、剪纸。卡面不打印样式名。
- 尺寸：小方卡、横向中卡、大方卡；Android 使用固定 2×2、4×2、4×4，不提供任意拉伸。其他宿主采用对应系统尺寸。
- 外观：跟随系统、浅色、深色。四季图按实际季节切换。

统计内容进入统计，最近阅读区域继续上次的书籍和位置，纪念打开历史，摘录打开书签。多条摘录时显示“换一条”，只切换当前组件；没有记录时不伪造书籍或统计。

Android 添加时打开与 App 共用的配置页面，取消不会覆盖原卡片；HarmonyOS 通过表单配置入口选内容。iOS 编辑使用 WidgetKit 的系统界面，不能由 App 替换；交互式摘录切换需要 iOS 17 或更高版本。系统负责桌面刷新时机，小组件不会持续运行动画。

源码预览使用独立包名和容器。iOS 构建前需要配置自己的签名，并使主应用与扩展使用同一个 App Group。
